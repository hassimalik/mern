**Steps in Creating a Full Stack MERN APP**

1. Create a folder named backend
2. Go to backend and then install dependencies `npm i express mongoose dotenv cors` and `npm install -d nodemon`
3. Create a file of server.js. Server.js has following functions like it:
- Starts Application
- Load Environment variables
- Create Express App
- Connect database
- Start Listening
4. After creating a server.js file we import and use the express to start the app on a desired port.
5. We create a dir src and create a file name `app.js` in it.
6. We import and exported express to use it in server.js file.
